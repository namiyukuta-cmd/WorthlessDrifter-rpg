# 目パーツ置き場

目パーツはここにPNGで置く。

- `eyes_01.png`
- `eyes_02.png`
- `eyes_03.png`
- 以後同じ命名規則

ルール:

- すべて `assets/avatar/base/base_01.png` と同じキャンバスサイズにする。
- キャンバス内のキャラクター位置も素体と完全に合わせる。
- 目以外の部分は透明にする。
- 目ごとに切り抜きサイズや配置座標を変えない。
- ゲーム側では全目パーツを `left:0; top:0; width:100%; height:100%` 相当で重ねる。
- 個別のX/Y補正、拡大縮小はしない。
- 素体PNGは変更しない。
- SVG化、トレース、再描画、Photonなどによる変換・再圧縮はしない。

表示順は、素体 `z-index:0`、目 `z-index:10`。

セーブデータでは `state.avatar.eyes` に `01`、`02` のような番号を保存する。未設定は `none`。
