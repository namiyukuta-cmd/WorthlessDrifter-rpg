# 街の片隅 — 生活サバイバル

日本語で遊べる、スマートフォン対応のオリジナル・ブラウザゲームです。

## 遊び方

`index.html` をブラウザで開くと始まります。現在地で行動を選ぶか、街の別の場所へ移動します。空腹・体力・健康・体温・衛生・気分と所持金を管理して、生活を立て直してください。

- 商店街：食事、生活用品、物乞い
- 駅前：求人情報、面接、継続勤務、物乞い、軒下での宿泊
- 公園：資源回収、休憩、水場、物探し、野宿
- 支援センター：無料食、シャワー、健康相談、書類手続き、シェルター
- 図書館：学習、休憩、水の補充
- 倉庫街：日雇い労働、資源回収、簡易宿泊所

**目標**：書類3、就労記録3、申込金20,000円をそろえ、支援センターで住まいを申し込むこと。

進行はブラウザのローカルストレージに自動保存されます。

## 公開方法

GitHub Pages を使う場合、公開元のブランチとルートフォルダの設定によって `/<リポジトリ名>/street-life-game/` のようなURLで遊べます。専用リポジトリにする場合は、このフォルダのファイルをルートに配置してください。
